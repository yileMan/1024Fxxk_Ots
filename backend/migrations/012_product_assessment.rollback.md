# 012 product_assessment 回滚说明

1. 停止内部 OTS 匹配、产品评估任务生成及所有评估/审核写入，并完整备份 `product_assessment`。
2. 若表为空，可在确认应用已回滚到 OTS-10 之前版本后直接删除。
3. 若仅存在系统生成且从未填写、提交或审核的 `pending/reassess` 待办，必须先导出业务键、负责人、来源基准和修订链；经业务负责人确认可由候选关系重新生成后才能删除。
4. 若存在任何用户填写内容、`submitted/returned/completed` 状态或审核留痕，禁止直接回滚。必须先导出全部修订和审核证据并取得业务处置确认；不得通过级联删除规避检查。
5. 满足上述前置条件后执行：

```sql
DROP TABLE product_assessment;
```

该操作不删除第 8 张表漏洞事实或第 9 张表候选关系。恢复时重新执行 `012_product_assessment.sql`，再按仍承载当前漏洞事实的成功批次重新执行内部匹配，以幂等补齐系统待办；用户评估和审核历史只能从备份恢复。
