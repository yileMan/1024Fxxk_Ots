# 009 import_batch 回滚说明

`import_batch` 保存离线包、原始范围快照和逐 OTS 覆盖历史。回滚前必须先停止应用，并确认 OTS-07 及其后续迁移尚未部署、没有下游表外键引用本表。

1. 执行 `SELECT COUNT(*) FROM import_batch;`，仅当确认表为空时继续。
2. 如果表内已有记录，必须先完成可验证备份并停止回滚；不得把删除历史作为普通版本回退手段，应采用向前修复迁移。
3. 禁止使用级联删除绕过未来的漏洞或评估引用。
4. 先回滚所有读取 `import_batch` 的应用版本，再人工执行：

```sql
DROP TABLE import_batch;
```

5. 回滚后检查 `schema_migration` 的版本管理策略，并验证既有 8 张应用基础表及其数据未受影响。
