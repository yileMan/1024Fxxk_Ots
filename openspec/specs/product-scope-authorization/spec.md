# 产品范围授权规范

## Purpose

为 OTS 管理平台建立可由管理员维护、由所有产品相关接口一致执行的产品级与版本级访问范围，使前端可见内容、服务端直接请求和后续评估操作共享同一授权边界。

## Requirements

### Requirement: 管理员维护用户产品范围
系统 MUST 仅允许具有 `admin` 角色的当前用户查询、授予和撤销用户的产品范围。授权 MUST 使用 `product` 或 `version` 两种固定类型：产品级授权必须关联存在的产品且不指定版本，版本级授权必须同时关联存在的产品及其所属版本；其他用户、类型不匹配或跨产品版本组合必须被拒绝。

#### Scenario: 管理员授予产品级范围
- **GIVEN** 当前用户具有 `admin` 角色，目标用户和产品均存在
- **WHEN** 管理员为目标用户授予该产品的 `product` 范围且不提交版本 ID
- **THEN** 系统保存该范围，并使目标用户获得该产品全部有效版本的访问范围

#### Scenario: 管理员授予版本级范围
- **GIVEN** 当前用户具有 `admin` 角色，目标版本存在且属于所提交产品
- **WHEN** 管理员为目标用户授予该版本的 `version` 范围
- **THEN** 系统保存该范围，且该授权本身不包含同产品的其他版本

#### Scenario: 拒绝无效或越权授权
- **GIVEN** 当前用户不是管理员，或提交了未知用户、未知产品、未知版本、非法范围类型或不属于该产品的版本
- **WHEN** 该用户提交范围查询、授予或撤销请求
- **THEN** 系统返回稳定的权限或字段级错误，不改变任何授权且不写入 `audit_log`

#### Scenario: 重复授予保持幂等
- **GIVEN** 目标用户已经具有相同类型和目标的范围
- **WHEN** 管理员再次授予完全相同的范围
- **THEN** 系统返回现有范围而不创建重复记录
- **AND** 系统不新增重复审计记录

#### Scenario: 撤销单条范围
- **GIVEN** 目标用户同时具有多个产品级或版本级范围
- **WHEN** 管理员撤销其中一条现有范围
- **THEN** 系统仅移除指定范围，并按剩余范围重新计算有效访问集合
- **AND** 不删除用户、产品、产品版本或历史业务记录

### Requirement: 统一计算有效产品与版本范围
系统 MUST 将同一用户的全部范围按并集计算。具有 `admin` 角色的当前用户 MUST 具有全局产品与版本读取范围；其他当前用户仅可读取其有效范围内的数据。产品级范围 SHALL 包含该产品全部 `active` 版本，版本级范围 SHALL 仅包含指定且为 `active` 的版本；`disabled` 产品或版本不得成为普通用户的有效范围，但其授权记录必须保留以维持历史引用。

#### Scenario: 产品级范围包含全部有效版本
- **GIVEN** 普通用户具有产品 A 的产品级范围，产品 A 有两个有效版本和一个停用版本
- **WHEN** 用户查询可见产品和版本
- **THEN** 系统返回产品 A 及其两个有效版本，不返回停用版本

#### Scenario: 版本级范围不扩展到同产品其他版本
- **GIVEN** 普通用户仅具有产品 A 版本 1 的版本级范围
- **WHEN** 用户查询产品 A 的版本列表或直接请求版本 2
- **THEN** 列表仅包含版本 1，且对版本 2 的直接请求返回明确的 403 权限错误

#### Scenario: 多条范围按并集合并
- **GIVEN** 普通用户同时具有产品 A 的产品级范围和产品 B 版本 2 的版本级范围
- **WHEN** 系统计算该用户的有效范围
- **THEN** 结果包含产品 A 的全部有效版本和产品 B 的版本 2
- **AND** 不包含产品 B 的其他版本

#### Scenario: 管理员全局读取
- **GIVEN** 当前用户具有 `admin` 角色且没有任何 `user_product_scope` 记录
- **WHEN** 管理员查询产品、版本或按产品版本限定的资源
- **THEN** 系统不因缺少范围记录而拒绝访问或裁剪结果

#### Scenario: 停用实体不再产生有效范围
- **GIVEN** 普通用户的现有范围引用了后来被停用的产品或版本
- **WHEN** 用户查询列表或直接请求该实体下的受保护资源
- **THEN** 系统从有效范围中排除该产品或版本，并对直接请求返回明确的 403 权限错误
- **AND** 原授权记录及其审计历史继续保留

### Requirement: 角色、范围与业务分配共同约束操作
系统 MUST 将固定角色、有效产品范围和资源级业务条件分别校验，授权范围不得赋予用户角色本身不允许的操作。后续产品评估接口还 MUST 校验当前用户是否为产品版本当前指定负责人或当前指定审核人；管理员的全局范围不得绕过负责人、审核人或禁止自审等业务动作规则，除非管理员同时满足该动作要求。

#### Scenario: 范围不提升角色权限
- **GIVEN** 用户具有某产品版本范围但不具有目标写操作要求的固定角色
- **WHEN** 用户直接请求该写操作 API
- **THEN** 系统返回明确的 403 权限错误且不修改业务数据或写入 `audit_log`

#### Scenario: 负责人在授权版本执行负责人动作
- **GIVEN** 用户具有 `product_owner` 角色、目标产品版本的有效范围，且是该版本当前指定负责人
- **WHEN** 用户请求该版本的负责人专属动作
- **THEN** 系统允许请求进入该动作自身的业务校验

#### Scenario: 指定人员缺少范围时被拒绝
- **GIVEN** 用户是产品版本当前指定负责人或审核人，但不具有该版本的有效范围
- **WHEN** 用户请求负责人或审核人专属动作
- **THEN** 系统返回明确的 403 权限错误，不读取受保护详情且不产生业务变更

### Requirement: 产品相关接口执行相同的服务端范围规则
系统 MUST 对产品相关列表、详情、写入、评估、审核和导出接口使用同一有效范围语义。列表 MUST 在查询时裁剪为有效范围；详情和动作接口 MUST 在返回业务内容或执行操作前校验范围；通过猜测 ID、修改 URL 或直接调用 API 不得绕过校验。

#### Scenario: 列表按范围裁剪
- **GIVEN** 普通用户仅具有产品 A 的有效范围，系统还存在产品 B
- **WHEN** 用户请求产品相关分页列表
- **THEN** 返回项与总数均只基于用户可见的产品 A 数据计算
- **AND** 响应不得泄露产品 B 的业务数据

#### Scenario: 直接 API 请求阻止越权
- **GIVEN** 普通用户知道一个不在其有效范围内的产品版本或下游资源 ID
- **WHEN** 用户绕过前端直接请求对应详情、写入、评估、审核或导出 API
- **THEN** 系统返回稳定的 403 权限错误，不返回受保护内容、不修改数据且不写入 `audit_log`

### Requirement: 授权变更与审计同事务提交
系统 MUST 将每次实际发生的范围授予或撤销与对应 `audit_log` 记录置于同一数据库事务。审计 MUST 记录操作者、目标用户、范围类型、产品、可选版本及动作；校验失败、权限拒绝、重复幂等请求或事务失败不得产生授权变更审计。

#### Scenario: 成功授予或撤销产生审计
- **GIVEN** 管理员提交有效且会改变当前范围集合的授予或撤销请求
- **WHEN** 授权事务成功提交
- **THEN** 系统同时提交授权变化和一条包含必要范围信息的 `audit_log` 记录

#### Scenario: 事务失败整体回滚
- **GIVEN** 授权记录或审计记录在提交时发生数据库错误
- **WHEN** 系统回滚事务
- **THEN** 授权集合与操作前一致，且不存在孤立授权或孤立审计记录

### Requirement: 前端授权配置与明确权限反馈
前端 SHALL 在用户管理中提供仅管理员可用的产品授权配置，区分产品级与版本级范围并显示其覆盖关系；认证后页面 SHALL 按当前用户角色和有效范围裁剪导航、列表及操作按钮。前端 MUST 对路由越权和 API 403 显示明确的无权访问页面或反馈，且不得将隐藏入口作为服务端授权的替代。

#### Scenario: 管理员配置用户范围
- **GIVEN** 管理员打开目标用户的授权配置且系统存在有效产品与版本
- **WHEN** 管理员授予或撤销产品级、版本级范围
- **THEN** 前端区分显示范围类型、目标产品与可选版本，并在成功后同步当前有效范围

#### Scenario: 普通用户仅看到允许入口
- **GIVEN** 普通用户已登录且仅具有部分产品版本范围
- **WHEN** 前端恢复当前用户并渲染导航、列表和操作入口
- **THEN** 前端仅显示其角色和范围允许的内容与动作，并正确呈现加载、空范围和服务错误状态

#### Scenario: 越权路由显示 403
- **GIVEN** 普通用户直接输入一个其角色或范围不允许的前端路由
- **WHEN** 路由权限校验或后端请求返回 403
- **THEN** 前端展示明确的无权访问页面或反馈，不把越权响应显示为资源不存在或空数据
