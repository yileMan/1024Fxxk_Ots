# cvss31-environmental-scoring Specification

## Purpose

本能力为产品评估提供可追溯的 CVSS v3.1 环境指标编辑与权威计算，确保来源向量、结构化指标、环境向量、分数和计算器版本保持一致，并明确阻止无来源评分及 v4.0 预留能力被误用。

## Requirements

### Requirement: 来源 CVSS v3.1 是环境评分前置条件
系统 MUST 仅在漏洞当前来源事实包含完整且合法的 CVSS v3.1 基础向量时提供产品环境评分；系统 SHALL 返回来源分数、严重度、向量、评分来源以及环境评分可用状态，但 MUST NOT 从其他版本、严重度文本或不完整指标自动生成或换算 v3.1 来源评分。

#### Scenario: 来源提供合法 v3.1 向量
- **GIVEN** 当前评估关联漏洞具有完整且合法的 `CVSS:3.1` 基础向量
- **WHEN** 有权用户读取评估详情
- **THEN** 系统返回原始来源 v3.1 信息并标记环境评分可用
- **AND** 前端展示来源向量和环境指标表单

#### Scenario: 来源未提供 v3.1
- **GIVEN** 当前评估关联漏洞没有 CVSS v3.1 来源向量
- **WHEN** 用户读取评估详情
- **THEN** 系统标记环境评分不可用并明确返回“来源未提供”语义
- **AND** 前端不展示可编辑环境指标或虚构的零分

#### Scenario: 来源向量不完整或非法
- **GIVEN** 来源字段包含无法解析、版本不为 `3.1` 或缺少任一基础指标的向量
- **WHEN** 用户读取或尝试保存该评估的环境指标
- **THEN** 系统不计算环境评分并返回稳定的来源向量不可用原因
- **AND** 不写入环境指标、派生结果或审计记录

### Requirement: 结构化环境指标与严格校验
系统 SHALL 支持 CVSS v3.1 环境指标 `CR`、`IR`、`AR`、`MAV`、`MAC`、`MPR`、`MUI`、`MS`、`MC`、`MI` 和 `MA`，并按 CVSS v3.1 允许值严格校验；每个未覆盖来源基础值或安全要求的可选指标 MUST 使用 `X` 表示 Not Defined，系统 MUST 拒绝未知指标、重复指标、非法枚举和 v4.0 指标。

#### Scenario: 保存合法环境指标
- **GIVEN** 来源具有合法 v3.1 基础向量且当前负责人拥有编辑权限
- **WHEN** 负责人保存一组只含支持键和值的环境指标
- **THEN** 系统规范化并保存完整结构化指标
- **AND** 未定义的支持指标以 `X` 的统一语义参与向量和分数计算

#### Scenario: 非法或未知指标
- **GIVEN** 来源具有合法 v3.1 基础向量
- **WHEN** 保存请求包含未知键、v4.0 键或某个 v3.1 指标不允许的值
- **THEN** 系统返回 `422`、稳定校验错误码和具体指标路径
- **AND** 不修改评估或审计记录

#### Scenario: 客户端提交重复或矛盾指标
- **WHEN** 请求以任何表示形式为同一指标提供多个值，或同时提交互相矛盾的结构化指标和环境向量
- **THEN** 系统拒绝该请求或仅接受契约声明的结构化指标字段
- **AND** 客户端提供的向量不得成为持久化结果的依据

### Requirement: 服务端权威计算分数与向量
系统 MUST 按 FIRST CVSS v3.1 规范从当前来源基础向量和已校验环境指标计算环境分数与规范化完整向量，正确应用 Modified Scope、Privileges Required、影响上限和 Roundup 规则；系统 SHALL 固定写入 `cvss_version=3.1` 及非空 `calculator_version`。客户端提交或篡改的分数、向量、CVSS 版本和计算器版本 MUST NOT 决定保存结果。

#### Scenario: 服务端计算并保存派生结果
- **GIVEN** 来源向量和环境指标均合法
- **WHEN** 当前负责人保存环境指标
- **THEN** 系统在同一次响应中返回服务端计算的单小数环境分数、规范化环境向量、`3.1` 版本和计算器版本
- **AND** 持久化值与响应一致

#### Scenario: 前端篡改分数无效
- **GIVEN** 客户端预览分数与服务端按同一指标计算的结果不同
- **WHEN** 客户端尝试在保存请求中附带伪造分数、向量或计算器版本
- **THEN** 系统忽略契约外派生字段或以 `422` 拒绝请求
- **AND** 绝不保存客户端决定的派生结果

#### Scenario: 清空所有环境覆盖指标
- **GIVEN** 当前草稿已保存环境指标和派生结果
- **WHEN** 当前负责人将全部环境指标恢复为 `X` 并保存
- **THEN** 系统保存规范化的未定义指标集合
- **AND** 环境向量和分数仍由来源基础指标按 v3.1 环境公式计算，而不是遗留旧结果

### Requirement: 预览与最终结果一致
前端 SHALL 在用户修改环境指标时提供即时预览并标明其为预览；保存成功后 MUST 以服务端返回的指标、分数、向量和计算器版本替换预览。预览无法计算、保存失败或发生并发冲突时，页面 MUST 保留用户输入且不得把预览显示为已保存结果。

#### Scenario: 指标变化即时预览
- **GIVEN** 页面已加载合法来源向量
- **WHEN** 用户改变任一环境指标
- **THEN** 页面无需先保存即可更新预览分数与向量
- **AND** 页面明确区分未保存预览和服务端已保存结果

#### Scenario: 服务端结果校正预览
- **WHEN** 环境指标保存成功
- **THEN** 页面以响应中的规范化指标、分数、向量和计算器版本刷新已保存结果
- **AND** 不继续展示旧预览为最终值

#### Scenario: 保存失败保留输入
- **WHEN** 保存因校验、权限、并发或服务错误失败
- **THEN** 页面保留尚未保存的指标选择并显示对应错误
- **AND** 已保存分数和未保存预览保持可区分

### Requirement: CVSS v3.1 兼容性回归与版本边界
计算行为 MUST 通过 FIRST CVSS v3.1 官方示例向量及边界组合回归验证，并 SHALL 对相同来源向量与指标产生确定性结果。V1 MUST NOT 导入、写入、返回、计算或展示 CVSS v4.0 数据，即使数据库存在相关预留字段或产品版本记录含有预留值。

#### Scenario: FIRST 官方示例一致
- **WHEN** 自动化测试输入 FIRST CVSS v3.1 官方示例的基础向量和环境指标
- **THEN** 系统生成的环境分数与完整向量和官方预期一致
- **AND** 临界舍入及 Modified Scope 变化均有回归覆盖

#### Scenario: 相同输入确定性计算
- **WHEN** 相同的规范化来源向量和环境指标被重复计算
- **THEN** 系统每次返回相同分数、向量和计算器版本

#### Scenario: v4.0 请求保持不可用
- **WHEN** 客户端请求、提交或尝试展示 CVSS v4.0 指标或派生结果
- **THEN** 系统拒绝该输入且 API 不返回 v4.0 评分字段
- **AND** 数据库中的 v4.0 预留字段保持未写入
