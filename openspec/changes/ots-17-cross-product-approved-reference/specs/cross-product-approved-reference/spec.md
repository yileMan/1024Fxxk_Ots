## Purpose

本能力为有权查看评估详情的用户提供相同 OTS/CVE 在其他产品中的当前已审核通过摘要，并以最小字段、只读交互和零副作用约束避免跨产品草稿或敏感评估信息泄露。

## ADDED Requirements

### Requirement: 以当前评估上下文定位其他产品参考
系统 SHALL 以用户有权查看的目标评估为入口，使用该评估对应的 OTS 与 CVE 查询其他产品参考；结果 MUST 排除目标评估所属产品，并 MUST 同时限定参考修订 `is_current=1`、`status=completed` 和 `review_decision=approved`。只有通过目标评估既有读取授权的用户才能发起查询；该最小已批准摘要可来自其日常产品范围之外，但目标评估不可见时系统 MUST 沿用既有不泄露详情的拒绝语义。

#### Scenario: 产品负责人查看其他产品当前批准摘要
- **GIVEN** 产品负责人有权查看目标评估，且另一产品对相同 OTS/CVE 存在当前已审核通过修订
- **WHEN** 用户加载目标评估的其他产品参考
- **THEN** 系统返回该其他产品的摘要
- **AND** 即使该参考产品不属于用户的日常产品范围，也只返回本能力规定的最小已批准摘要

#### Scenario: 当前指定审核人在同页查看参考
- **GIVEN** 当前指定审核人有权查看待审核目标评估
- **WHEN** 审核人加载同一详情页的其他产品参考
- **THEN** 系统按与产品负责人相同的 OTS/CVE、其他产品和批准当前修订条件返回摘要
- **AND** 参考查询不授予审核人对其他产品评估详情或编辑接口的访问权

#### Scenario: 排除当前产品的其他版本
- **GIVEN** 目标产品的另一个版本对相同 OTS/CVE 存在已审核通过的当前修订
- **WHEN** 用户查询其他产品参考
- **THEN** 系统不返回目标产品任何版本的评估摘要
- **AND** 其他产品的符合条件版本仍可返回

#### Scenario: 目标评估不可见
- **WHEN** 未认证用户、产品范围失效用户或其他无权用户使用评估 ID 请求参考
- **THEN** 系统沿用目标评估详情的认证、授权和不泄露资源存在性的错误语义拒绝请求
- **AND** 响应不包含目标或参考产品、OTS、CVE、状态及数量信息

### Requirement: 仅公开批准摘要字段白名单
每条参考摘要 MUST 只包含产品名称、产品版本、适用性、分析摘要、环境分数、处置方式和审核完成时间。API MUST NOT 返回评估 ID、产品内部证据、证据正文、审核意见、提交审核人员、草稿字段、修订链字段、行版本、可编辑能力、自动复评基线或变化摘要；缺失的允许字段 SHALL 明确返回空值而不得推断或改用其他敏感字段补齐。

#### Scenario: 返回固定最小摘要
- **WHEN** 某条其他产品评估满足全部参考筛选条件
- **THEN** API 响应只包含产品名称、产品版本、适用性、分析摘要、环境分数、处置方式和审核完成时间
- **AND** 前端仅使用这些字段构建只读摘要

#### Scenario: 已批准修订含内部证据和审核意见
- **GIVEN** 符合条件的参考修订保存了内部证据、审核意见、人员留痕及修订控制数据
- **WHEN** 用户通过 API 或页面查看参考
- **THEN** 响应与页面均不包含这些非白名单数据
- **AND** 用户不能从参考区域导航到该其他产品的评估详情

#### Scenario: 环境分数不可用
- **GIVEN** 符合条件的参考修订没有合法环境分数
- **WHEN** 系统返回该参考摘要
- **THEN** 环境分数返回空值且页面显示稳定的“未提供”提示
- **AND** 系统不得从来源分数、严重度或其他产品数据推断环境分数

### Requirement: 未批准或非当前修订不可见
系统 MUST 在数据库查询结果形成前排除草稿、待审核、已退回、待复评、审核决定非 `approved` 以及 `is_current=0` 的修订；同一其他产品版本出现历史批准修订但当前修订不再满足条件时，历史批准修订 MUST NOT 作为参考回退展示。

#### Scenario: 混合状态只返回合格记录
- **GIVEN** 相同 OTS/CVE 在其他产品中同时存在待评估、待审核、已退回、待复评、当前批准和非当前历史批准修订
- **WHEN** 用户查询其他产品参考
- **THEN** 系统只返回当前批准修订
- **AND** 响应不泄露被排除记录是否存在或其数量

#### Scenario: 当前修订替代历史批准修订
- **GIVEN** 某其他产品的历史修订已批准完成，但其当前修订为 `reassess`、`submitted` 或 `returned`
- **WHEN** 用户查询其他产品参考
- **THEN** 系统不返回该历史批准修订，也不返回当前未批准修订
- **AND** 不使用历史结果填补当前参考

#### Scenario: 没有合格参考
- **WHEN** 相同 OTS/CVE 不存在任何其他产品的当前批准修订
- **THEN** API 成功返回空集合
- **AND** 页面显示明确的无可用参考状态，不把空结果解释为其他产品不受影响

### Requirement: 参考区域只读且不能形成当前产品结论
前端 SHALL 在评估详情的候选匹配与当前产品结论之间展示“其他产品参考”区域，明确标记内容仅供参考，并提供独立的加载、失败、重试和空状态。页面 MUST NOT 提供复制、套用、自动填充或批量写入参考结论的操作，也 MUST NOT 因参考请求失败而阻止用户读取或操作其本来有权处理的当前评估。

#### Scenario: 成功展示多条参考
- **WHEN** 参考查询返回一条或多条摘要
- **THEN** 页面以只读方式逐条展示产品、版本和批准摘要字段，并显示“仅供参考”提示
- **AND** 页面不显示套用、复制到当前结论或打开其他产品详情的操作

#### Scenario: 参考查询失败后重试
- **WHEN** 目标评估详情加载成功但参考查询失败
- **THEN** 页面仅在参考区域显示可重试错误
- **AND** 当前产品结论、保存、提交或审核能力仍按目标评估详情的服务端结果工作

#### Scenario: 参考内容与当前表单字段相似
- **GIVEN** 参考摘要的适用性、分析摘要或处置方式与当前产品表单字段对应
- **WHEN** 用户查看、展开或刷新参考区域
- **THEN** 当前表单值及未保存输入保持不变
- **AND** 页面不自动选择、复制或合并任何参考值

### Requirement: 参考查询无业务写入副作用
加载、刷新、展开或重试其他产品参考 SHALL 是纯读取行为，MUST NOT 改变目标或参考评估的状态、`row_version`、当前修订标记、时间留痕或责任人分配，也 MUST NOT 写入 `audit_log`、创建修订或触发自动复评。

#### Scenario: 查看参考不改变当前任务
- **GIVEN** 目标评估处于任一可读取状态
- **WHEN** 用户加载、刷新或展开其他产品参考
- **THEN** 目标评估的状态、行版本、修订链和时间留痕保持不变
- **AND** 工作台待办归属和数量不因该读取发生变化

#### Scenario: 查询成功或失败均不写审计
- **WHEN** 参考查询成功、返回空集合、被拒绝或发生服务错误
- **THEN** 系统不为该读取写入 `audit_log`
- **AND** 不创建或修改任何产品评估记录
