## Why

当前评估详情已能展示来源事实、候选依据和本产品结论，但产品负责人和审核人仍无法在同页安全参考相同 OTS/CVE 在其他产品中的已审核结论。需要补齐受严格状态筛选和字段白名单约束的跨产品只读摘要，在不泄露草稿、内部证据或审核意见的前提下满足 FR-ASSESS-011、FR-REVIEW-001 和关键业务规则 17。

## What Changes

- 新增按当前评估查询“其他产品参考”的只读 API，仅返回相同 OTS/CVE、不同产品中同时满足 `is_current=1`、`status=completed`、`review_decision=approved` 的记录。
- 使用显式响应字段白名单，仅公开产品名称、产品版本、适用性、分析摘要、环境分数、处置方式和审核完成时间；不返回草稿、内部证据、审核意见、修订控制字段或编辑能力。
- 在评估详情中新增“其他产品参考”只读区域，供产品负责人和当前指定审核人查看，并明确标记“仅供参考”。
- 提供明确空状态，并禁止一键复制、自动填充或以其他方式把参考结论写入当前产品评估。
- 保证参考查询为纯读取：查看、刷新或展开参考不得改变当前任务状态、行版本或审计记录。
- 不新增数据库表、字段、索引或迁移；复用既有 11 表及已归档的 OTS-11、OTS-14 能力。

## Capabilities

### New Capabilities

- `cross-product-approved-reference`: 定义相同 OTS/CVE 的跨产品已审核当前摘要查询、最小字段披露、只读页面展示及无副作用边界。

### Modified Capabilities

无。

## Impact

- 后端：评估查询路由、schema、service 和 repository 增加只读参考查询；必须在数据库查询层完成同 OTS/CVE、其他产品及批准当前修订筛选。
- 前端：评估 API 类型与评估详情页增加只读参考区域、免责声明、加载/失败/空状态；不新增写操作。
- 契约与测试：更新 OpenAPI 及生成的 TypeScript 类型，补充字段白名单、状态隔离、产品排除、权限范围、零副作用、组件和系统 Chrome E2E 验证。
- 依赖：OTS-11 `vulnerability-catalog-and-workbench`、OTS-14 `assessment-submit-and-review`；复用 OTS-15/16 已确立的当前修订语义，不改变其状态机和复评规则。
- 非目标：跨产品评估复制、跨产品草稿/证据/审核意见访问、全局查询与追溯（OTS-19）以及评估导出（OTS-20）。
