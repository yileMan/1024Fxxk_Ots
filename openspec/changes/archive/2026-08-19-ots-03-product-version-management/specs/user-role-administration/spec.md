## MODIFIED Requirements

### Requirement: 左侧三项应用导航
认证后的前端 SHALL 在桌面布局中使用左侧导航和右侧内容区；左侧主导航 MUST 严格按“工作台、产品管理、用户与角色、运行状态”四个条目排列，并明确显示当前路由。仅当前用户具有 `admin` 角色时，才显示并允许访问“产品管理”；非管理员直接访问产品管理路由时 MUST 展示明确的无权访问页面。小屏幕可以折叠导航，但条目名称、顺序和权限行为不得改变。

#### Scenario: 管理员查看应用外壳
- **GIVEN** 当前用户已登录并具有 `admin` 角色
- **WHEN** 用户进入任一认证后页面
- **THEN** 左侧依次显示“工作台”“产品管理”“用户与角色”“运行状态”四个导航条目
- **AND** 当前页面对应条目具有文字、形状或位置之外的可感知选中状态

#### Scenario: 非管理员访问用户与角色
- **GIVEN** 当前用户已登录但不具有 `admin` 角色
- **WHEN** 用户查看左侧导航或直接访问“产品管理”或“用户与角色”路由
- **THEN** 左侧不显示这两个管理员导航项，且前端展示明确的无权访问页面
- **AND** 相应服务端 API 仍执行管理员授权校验
